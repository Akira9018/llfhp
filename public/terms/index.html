UNITY by LLF合同会社

利用規約

制定日：2026年5月1日

本利用規約（以下「本規約」）は、LLF合同会社（以下「当社」）が提供するマッチングプラットフォーム「UNITY」（以下「本サービス」）の利用条件を定めるものです。会員登録をもって本規約に同意したものとみなします。

第1条（定義）

本規約において使用する用語の定義は以下のとおりです。

  1. 「会員」とは、本規約に同意の上、当社所定の手続きにより会員登録した法人または個人をいいます。
  2. 「施設会員」とは、介護・福祉施設として登録した会員をいいます。
  3. 「MSW会員」とは、医療ソーシャルワーカーとして登録した会員をいいます。
  4. 「プラン」とは、施設会員が選択する月額利用プランをいいます。

第2条（会員登録）

本サービスは招待制です。当社が発行する招待メールを受け取った方のみ会員登録できます。虚偽の情報で登録した場合、当社は登録を取り消すことができます。

第3条（料金プランおよびお支払い）

  1. 施設会員は以下のプランから選択できます。
    • 無料プラン：¥0/月。問い合わせの受信と施設情報の登録のみ可能。
    • ライトプラン：¥10,000/月（税別）。月3件まで「対応可能」返信が可能。
    • プロプラン：¥30,000/月（税別）。返信数無制限。
  2. 有料プランの料金は、Stripe Inc.が提供する決済システムを通じて、月次で前払いにより請求されます。
  3. プランの変更は当社管理画面からいつでも行えます。アップグレードは即時反映、ダウングレードは当該請求期間終了後に反映されます。

第4条（解約・返金）

  1. 会員はいつでも解約の申し出ができます。解約後も当該請求期間終了日まではサービスを利用できます。
  2. 既に支払われた料金の返金は、原則として行いません。ただし、当社の責に帰すべき事由によりサービスが提供できなかった場合はこの限りではありません。
  3. 日割り計算には対応していません。
  4. Stripe Inc.の決済処理に関する詳細は、Stripeサービス規約をご参照ください。

第5条（禁止事項）

会員は以下の行為を行ってはなりません。

  1. 虚偽の情報を登録する行為
  2. 他の会員への迷惑行為・ハラスメント行為
  3. 本サービスを通じた不正な営業活動
  4. 本サービスのシステムへの不正アクセス
  5. 法令または公序良俗に反する行為
  6. その他、当社が不適切と判断する行為

第6条（サービスの停止・変更）

当社は、システムメンテナンス、障害対応、その他やむを得ない事情により、事前通知なくサービスを一時停止または変更することがあります。これによって会員に生じた損害について、当社は責任を負いません。

第7条（免責事項）

  1. 本サービスは、施設とMSWをつなぐ場を提供するものであり、当社は両者間の契約・交渉の当事者ではありません。
  2. 会員間のトラブルについて、当社は一切の責任を負いません。
  3. 本サービスの利用によって生じた損害（逸失利益を含む）について、当社の責任は月額利用料の1ヶ月分を上限とします。

第8条（個人情報の取り扱い）

当社が取得した個人情報は、プライバシーポリシーに従い適切に管理します。

第9条（規約の変更）

当社は必要に応じて本規約を変更することがあります。変更後の規約は本ページへの掲載をもって効力を生じます。変更後も本サービスを利用した場合、変更後の規約に同意したものとみなします。

第10条（準拠法・管轄）

本規約は日本法に準拠します。本サービスに関する紛争については、大阪地方裁判所を第一審の専属的合意管轄裁判所とします。
